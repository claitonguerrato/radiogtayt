Integração com YouTube
As faixas pré-definidas de cada estação (as que já vêm no código, sem MP3 anexado) tocam automaticamente pelo YouTube — o app busca o vídeo pelo nome da música + artista e reproduz o áudio dele. Não é preciso conectar nenhuma conta: só uma chave gratuita da YouTube Data API v3, criada no Google Cloud Console (console.cloud.google.com → APIs e Serviços → Credenciais → Criar chave de API, com a "YouTube Data API v3" ativada no projeto).
